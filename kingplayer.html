강력한 재생 엔진 & HDR

영상이 클수록 플레이어의 차이가 드러납니다. 고해상도부터 HDR까지 자동으로 가장 좋은 재생 방식을 선택합니다.

  • 고품질 렌더링. 4K · 5K · 8K · 16K 완벽 지원
  • HDR 완전 지원 (PQ / HLG / Dolby Vision 자동 감지)
  • 톤매핑 8종 (ACES / Reinhard / Hable / Mobius / BT.2390 / ST.2094-10 등)
  • Windows HDR 자동 전환 5단계 + SDR 변환 + 로컬 톤매핑
  • 10 / 12 / 16-bit 색심도 (HEVC / AV1 10bit 등)
  • 하드웨어 가속 (DXVA2 / D3D11 / CUDA / QuickSync) 자동 선택
  • 재생 속도 0.1x ~ 4.0x (피치 보존)
  • 구간 반복 / 구간 자르기 (스트림 복사 초고속)
  • 영상 회전 / 좌우·상하 반전 / 색상 조정 자동 복원
